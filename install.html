Adding Genny to Claude

Two minutes. You need a Claude account on a plan that supports custom connectors, and your Generation6 email address.

  1. Open Claude's connector settings In the Claude app: Settings → Connectors → Add custom connector.
  2. Paste the address
  3. Claude will ask you to sign in A Genny page opens asking for your email. Use your @generation6.com address.
  4. Enter the six-digit code It arrives by email within a few seconds. Check spam the first time.
  5. You're connected Genny appears in Claude's connector list. It stays connected — you won't be asked again unless access changes.
  6. Try it Ask something you'd actually want to know:
    • What does the Academy teach about triangulation?
    • What have we published on next-generation ownership education?

If something goes wrong

My address wasn't recognised

Genny only accepts @generation6.com addresses unless yours has been added individually. If you should have access with a different address, ask — it takes a minute to add.

The code never arrived

Check spam first. If it's genuinely missing, try again — a new code invalidates the old one. Codes expire after a few minutes.

Claude says the connector is disconnected

Remove it and add it again. If it fails a second time, that's worth reporting rather than retrying — it usually means something on our side.

"Rate limit reached"

There's a ceiling of 40 questions an hour, which exists to stop runaway loops rather than to ration you. Normal use never reaches it. If you hit it in ordinary work, tell us — the limit is wrong, not you.
